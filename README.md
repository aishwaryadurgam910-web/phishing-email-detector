# Phishing Email Detector Using Python

## About the Project

This is a beginner-friendly Python cybersecurity project that checks email messages for suspicious phrases and URL patterns. It calculates a risk score and displays a risk level.

## Features

* Detects predefined suspicious phrases.
* Checks for suspicious URL patterns.
* Calculates a risk score.
* Displays Low, Medium, or High risk levels.

## Technologies Used

* Python
* Visual Studio Code

## How to Run

1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the Python file:

```bash
python phishing_detector.py
```

5. Enter an email message when prompted to see the analysis.

## Disclaimer

This is a basic, rule-based learning project. It cannot guarantee that an email is safe or malicious.
